# Project Structure & Implementation Plan

We are building `cla-ca-research-platform` adhering strictly to the user's requirements: separate files for normalization, dataset loading, feature weighting, discretization, valley detection (Createsplit), scoring, prediction, evaluation, FastAPI backend, and React frontend.
